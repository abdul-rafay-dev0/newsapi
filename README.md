# 📰 News App — Python

A simple command-line news application built in Python that fetches and displays live news headlines from the **News API** using the `requests` module.

---

## 🎯 Features

- ✅ Fetch top headlines from the US
- ✅ Display news titles, sources, and URLs
- ✅ Filter news by category (optional)
- ✅ Simple and easy to use

---

## 🛠️ Technologies Used

- Python 3
- Requests Module
- News API

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/abdul-rafay-dev0/newsapi.git
   ```
2. Navigate to the project folder:
   ```bash
   cd newsapi
   ```
3. Install the required library:
   ```bash
   pip install requests
   ```
4. Get your free News API key from [newsapi.org](https://newsapi.org)
5. Open `newsapi.py` and replace `YOUR_API_KEY` with your actual API key:
   ```python
   api_key = "YOUR_API_KEY"  # Replace with your actual key
   ```
6. Run the app:
   ```bash
   python newsapi.py
   ```
